# Awesome Bun projects

The upstream community list is [`oven-sh/awesome-bun`](https://github.com/oven-sh/awesome-bun). GitHub metadata shows it as CC0-1.0 and last pushed 2025-07-20 in the 2026-11-04 audit. Treat it as a source index, not a current compatibility guarantee. Preserve the upstream link and license when syncing entries.

## Source categories to track

- Bun runtime and core packages: [`oven-sh/bun`](https://github.com/oven-sh/bun).
- Runtime and bundler plugins: Bun's [runtime plugin API](https://github.com/oven-sh/bun/blob/main/docs/runtime/plugins.mdx) and [bundler plugin API](https://github.com/oven-sh/bun/blob/main/docs/bundler/plugins.mdx).
- Official VS Code integration: [`packages/bun-vscode`](https://github.com/oven-sh/bun/tree/main/packages/bun-vscode).
- Community projects: see and sync from [upstream Awesome Bun](https://github.com/oven-sh/awesome-bun); verify each project's current source, license, last activity and Bun compatibility before promoting it.
- YOLO integrations: `yolo-bun` packages listed in [`projects.json`](projects.json), with implementation status kept explicit.

## Listing policy

This file intentionally does not copy the full upstream list. Each imported project should retain its original repository URL and license and be checked against the current project itself. Do not infer that an entry is maintained merely because it remains in an Awesome list.
